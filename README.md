# Merge unaligned eprime and subsequent results
**Note: Installation and usage instructions coming up soon**

This repository contains code that does the following:

1. E-Prime merged with Journal: These two files need to be merged according to ID_BIOPAC (E-prime) & Index (Journal)
2. E-prime+Journal merged with SCR: These two files need to be merged accourding to Time (Journal file) & Stim Time (SCR file, highlighted). 

Made for the Developmental Psychology department at the Tilburg School of Social and Behavioural Sciences, Netherlands.
